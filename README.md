# Model-as-a-Paper

Scientific-paper-only language modeling with resumable training and verified knowledge correction.

## Implementation status

The trainable MAP-44M v0.1 implementation is being prepared on a review branch.
This initial commit is only the repository bootstrap; it does not contain a trained model.

Research decisions: 44,577,280 parameters, scratch training, paper-derived data,
GQA, tied embeddings, explicit checkpoint/resume, supervised corrections and replay.

No corpus, model weights, credentials, or cloud-training jobs are included here.
No open-source license has been selected yet.
